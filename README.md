# Sao lưu Bentar Second Brain

Repo RIÊNG TƯ này giữ bộ não thứ hai. Lịch sử commit là các phiên bản của bộ não theo thời gian.

- `tri-nho.json`: toàn bộ trí nhớ (ghi nhớ, liên kết) – dữ liệu gốc để khôi phục.
- `tri-nho.md`: bản đọc được bằng mắt.
- `settings.ini`: cài đặt của app.

Khôi phục: cài Bentar Second Brain, chọn "Khôi phục bộ não", đăng nhập GitHub và chọn repo này.
Lưu ý: dữ liệu không mã hoá – ai vào được tài khoản GitHub hoặc repo này đều đọc được. Giữ repo ở chế độ riêng tư.
