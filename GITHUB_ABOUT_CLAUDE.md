## Claude Code cần thực hiện

1. Đọc `README.md`, xác nhận các mô tả trên vẫn khớp với chức năng hiện hành.
2. Cập nhật repository **About description** và **Topics** trên GitHub với nội dung phía trên. Đây là metadata của repository, không phải nội dung README; chỉ sửa README nếu phát hiện cần đồng bộ một đoạn mô tả ngắn.
3. Giữ repo public/private và các thiết lập quyền hiện có; không thay đổi cài đặt khác.
4. Kiểm tra trang repo sau khi lưu để xác nhận description và đủ topics hiển thị.

Nếu phiên GitHub chưa đăng nhập hoặc token không hợp lệ, yêu cầu chủ repo đăng nhập lại rồi tiếp tục; không thay đổi token, credential hay cấu hình xác thực tự động.
